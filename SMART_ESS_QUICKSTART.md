# Швидкий старт - Smart ESS

## Налаштування для користувачів

1. **Відкрийте сторінку налаштувань**: http://localhost:3000/settings/smartess

2. **Заповніть форму**:
   - Smart ESS User Name: ваш логін з додатку Smart ESS Monitor
   - Smart ESS Password: ваш пароль з додатку Smart ESS Monitor
   - Інвертор ID: Device ID з додатку (як знайти - дивіться інструкцію праворуч)

3. **Натисніть "Зберегти"** - система автоматично:
   - Збереже облікові дані
   - Оновить Device ID в алгоритмах
   - Виконає Discovery та налаштує інвертор

## Де знайти Device ID?

Детальна інструкція доступна:

- В правій колонці на сторінці налаштувань: http://localhost:3000/settings/smartess
- Окремою публічною сторінкою: http://localhost:3000/docs/smartess-setup

## Технічна інформація

Повну технічну документацію дивіться в [SMART_ESS_SETUP.md](./SMART_ESS_SETUP.md)

## Що відбувається під капотом?

1. Збереження `smart_ess_creds` в user properties
2. Оновлення `device_id` в `algorithm1` та `algorithm2` (якщо вони існують)
3. Виклик `Smartessapi.Discovery()`:
   - Аутентифікація в Smart ESS API
   - Отримання списку пристроїв
   - Пошук потрібного інвертора за Device ID
   - Налаштування полів управління
   - Збереження конфігурації

## Можливі проблеми

**"Не вдалося налаштувати інвертор"**

- Перевірте правильність username/password
- Переконайтеся що Device ID введено без помилок
- Перевірте що інвертор підключений до інтернету

**"Будь ласка, введіть..."**

- Всі три поля обов'язкові для заповнення
- Не можна залишати порожні значення

## System Settings

Для роботи потрібні системні налаштування:

- `dessmonitor_url`: URL Smart ESS API
- `dessmonitor_comp_key`: Company Key

Налаштовуються адміністратором через system settings.
