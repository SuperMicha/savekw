## Як тестувати

### 1. Запуск локально

```bash
npm run dev
```

Сервер буде доступний на http://localhost:3000

### 2. Надання admin прав

Локально треба встановити `isAdmin = true` для вашого користувача в БД:

```sql
-- Підключитись до локальної БД
psql -U postgres -d savekw_local

-- Знайти свого користувача
SELECT id, email, is_admin FROM users WHERE email = 'ваш@email.com';

-- Встановити admin права
UPDATE users SET is_admin = true WHERE email = 'ваш@email.com';
```

## Troubleshooting

### Logger не пише в БД

- Перевірити чи запущена міграція
- Перевірити чи є модель `AlgorithmLog` в Prisma Client
- Запустити `npx prisma generate`

### Admin сторінка не відображається

- Перевірити `isAdmin = true` для вашого користувача
- Перевірити консоль браузера на помилки
- Перевірити Network tab - чи викликається tRPC endpoint

### ServerInfo не показує дані

- Деякі метрики можуть не працювати на Windows (df, nginx logs)
- На продакшн сервері все має працювати
